Chess Pipeline Evolution

Can factory's evolutionary outer loop teach an LLM to beat Stockfish? Each move runs a Package pipeline through the real WorkflowExecutor. Best config locked from 8000 experiments. Factory tunes 5 remaining knobs via KNOB_MUTATE (guided by knob-contrastive reflection) and rewrites agent prompts via PROMPT_MUTATE (Opus analyzes blunders, rewrites full prompts — not append, replacement). Scored by wins (+500), draws (+200), position quality, and survival.

Package Composition

# Each chess move runs this pipeline.
# Sequential chains the phases in order.
pipeline = Sequential(

    # Phase-routed analysis via Conditional:
    # opening → lightweight, mid → all 3 parallel,
    # endgame → specialized king+pawn focus
    Conditional(phase_gate, {
      "opening": opening_pkg,
      "middle":  Parallel(anal, tact, pos),
      "endgame": endgame_pkg,
    }),

    # Verify loop: combined critique + blunder
    # check in one call. Loops back to selector
    # if issue found.
    Loop(
        Sequential(selector_pkg, verify_pkg),
        verify_gate, max_iterations=2,
    ),
)

wf = pipeline.compile()  # → flat DAG
await WorkflowExecutor(wf, proj).execute()

# ── 5 tunable knobs ──────────────

OptKnob("verify_style",
  bounds=["strict", "standard",
          "lenient"])
OptKnob("verify_iterations",
  bounds=[1, 2, 3])
OptKnob("critique_style",
  bounds=["devils_advocate",
          "sanity_check"])
OptKnob("use_verification",
  bounds=[True, False])
OptKnob("opening_hint",
  bounds=["theory", "principled"])
